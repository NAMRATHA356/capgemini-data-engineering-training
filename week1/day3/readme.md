Overview

This repository contains SQL practice problems focused on:

CASE WHEN logic
Nested CASE statements
Conditional data classification
Window functions (ROW_NUMBER, RANK, DENSE_RANK)

The assignment is designed to simulate real-world business scenarios using structured SQL queries.
